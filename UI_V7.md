# Circuvia UI v7

The UI has been redesigned for clarity and a more professional product feel.

Key improvements:
- Higher contrast and cleaner spacing
- Larger, clearer component symbols
- Better component cards and pin labels
- Cleaner three-panel simulator layout
- More readable inspector, code and console areas
- Less visual clutter on the canvas
- Consistent dashboard/content-page styling
- Responsive behavior for smaller screens

The existing component placement and wiring logic are preserved.
