# Circuvia Original SVG Symbol Engine

Circuvia now renders original vector component symbols locally rather than pulling component images from Tinkercad or another simulator.

The symbol library is in `svg-symbols.js`. Each supported component has an original SVG drawing. Pin names remain driven by `components.js`, so the visual symbol and simulator pin model stay separate and can be extended independently.

This is an original vector UI layer, not copied Tinkercad artwork.
