# Circuvia v8 — Realistic Component Layer

The simulator now uses a realistic, physical-component visual layer inspired by professional browser simulators:
- Arduino UNO/Nano/Mega board-style bodies
- ESP32/ESP8266 dev boards
- breadboard
- HC-SR04
- DHT11/DHT22
- LED, resistor, push button, potentiometer
- DC motor and servo
- L298N, relay, MPU6050
- OLED/LCD
- buzzer and transistor packages
- generic realistic fallback for other modules

Pins remain separate, clickable simulator elements so the physical-looking visuals do not break wiring.
