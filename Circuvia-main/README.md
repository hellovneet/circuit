# Circuvia
IoT & Electronics Simulation Studio

Developer: Vineet Sharma

## Current MVP
- Component library with Arduino UNO, ESP32, LED, resistor, push button, DHT11, HC-SR04, DC motor, BC547 NPN, diode, L298N, battery and more
- Drag/drop-style placement
- Wire drawing between component pins
- Delete selected components/wires
- Property panel
- Starter circuit templates
- Code editor panel
- Run/Stop simulation UI
- Console
- Local save/load using browser localStorage
- Responsive interface

## Important
This first build is the visual simulator foundation. It does not yet execute arbitrary Arduino C++ code electrically. The next engine phase can add component-specific behavior, GPIO state simulation, PWM, sensor controls, motor models and wiring validation.


## UI Theme
The current build uses a clean white/light UI with a light grid workspace for clearer component visibility.
