# Circuvia — Vercel Deployment

This is a static HTML/CSS/JavaScript project.

## Vercel
Import the project from GitHub, or deploy the extracted folder with the Vercel CLI.

No build command is required.
No output directory is required.
Framework preset: Other.

Entry pages:
- `/` → dashboard
- `/simulator` → simulator
- `/components` → component catalog
- `/tutorials` → tutorials
- `/docs` → docs
- `/about` → about

Do not upload the ZIP itself as the website root. Extract it first, or deploy the repository/folder.
