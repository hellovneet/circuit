# Circuvia v9 — Expanded Component Catalog

Added 107 new component definitions to the existing library.

The catalog now covers boards, basic electronics, transistors, motors/drivers, sensors, displays, communication modules, power modules, input devices, output devices and logic ICs.

Total definitions in `components.js`: 167.

All entries expose pins and properties, so they appear in the component library and can be placed on the simulator canvas. Unknown visuals use Circuvia's realistic fallback renderer rather than external simulator assets.
